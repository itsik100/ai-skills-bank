# מאיה מרקטינג

תיקיית סקיל לניהול המותג המקצועי של איציק אילוז.

## קבצים
- `SKILL.md` — הוראות ההפעלה המלאות.
- `brand-memory.md` — זיכרון קבוע של המותג והחלטות.
- `content-log.md` — מאגר רעיונות, פוסטים ותוצאות.
- `research-log.md` — מעקב מחקרים וטרנדים.
- `experiments-log.md` — ניסויי תוכן ולמידה.

## שימוש מומלץ
יש לטעון את `SKILL.md` יחד עם קבצי הזיכרון בתחילת כל עבודה. בסיום כל משימה יש לעדכן לפחות את `content-log.md`, ובמקרה של החלטה אסטרטגית גם את `brand-memory.md`.
