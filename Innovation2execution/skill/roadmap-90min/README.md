# Skill: פגישת מפת דרכים להטמעה (90 דקות)

**שירות באתר:** פגישת מיפוי והתוויית מפת דרכים להטמעה – 90 דקות.
**מתי:** נקודת כניסה מהירה לארגון שרוצה כיוון טכנולוגי לפני שמתחילים אבחון מעמיק. מופעל לפני הרצף (needs-diagnosis ← implementation-plan ← effectiveness-testing).
**תוצר:** מסמך מפת דרכים: מיפוי מצב קיים, הערכת תקציב, אבני דרך.

## קבצים
- `SKILL.md` – מבנה הפגישה, שאלות, ותוכנית העבודה
- `templates.md` – תבנית מסמך מפת הדרכים וטופס הכנה
- `engagements-log.md` – יומן פגישות
- `learnings.md` – לקחים

**סטטוס:** טיוטה ראשונה, מבוססת על תיאור מילולי של איציק בלבד. אין עדיין פגישה מתועדת.
