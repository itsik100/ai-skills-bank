# Skill Set: תוכנית הטמעה ואימוץ

**מיקום ב-repo:** `Innovation2execution/skill/implementation-plan/`
**מקור:** פרויקט "ראוי לציון" (מיתר, סיילספורס): תוכנית הטמעה שנכתבה אחרי שלב האיפיון, עם בסיס מחלקתי והרחבה מדורגת. מסגרת תיאורטית: CFIR + UTAUT + NASSS.
**חשוב:** נבנה ממקרה אחד בלבד. ראו "פערים פתוחים" ב-`SKILL.md`.

## מה יש בתיקייה
| קובץ | תפקיד |
|---|---|
| `SKILL.md` | ליבת הסקיל: קלט, מיפוי מהאבחון, שלבי התוכנית ותנאי מעבר, עקרונות, כיסוי CFIR |
| `templates.md` | שלד תוכנית הטמעה, תבנית אפיון לשדה, תפקידים, מדדים, סיכונים |
| `engagements-log.md` | יומן פרויקטים אמיתיים |
| `learnings.md` | עקרונות קבועים (כרגע ראשוניים, ממקרה אחד) |

## קובץ ידע קשור
`Innovation2execution/knowledge/technical-fit-checklist.md`: בדיקת התאמה טכנית אובייקטיבית של הפתרון (תחום "החדשנות" ב-CFIR). נטען לפני שנועלים את שלב הבנייה.

## הקשר לשאר המערכת
- **קלט:** תוצר `needs-diagnosis` שלב ב' (אפיון עסקי מאושר + פתרון נבחר)
- **פלט:** תוכנית שמעבירים לביצוע, ואחריה `effectiveness-testing` למדידה
- **כלי אבחון משותף:** `knowledge/fishbone-adoption-model.md`

## עדכון בסוף שיחה
