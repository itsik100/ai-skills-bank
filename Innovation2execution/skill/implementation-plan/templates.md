# תבניות: תוכנית הטמעה ואימוץ

מקור: תוכנית "ראוי לציון" (מיתר, סיילספורס). התבנית מוכללת: ניסוחים ייחודיים לסיילספורס או לקורפורט הוחלפו בשדות כלליים.

## תבנית 1: שלד תוכנית הטמעה

```
תוכנית הטמעה: [שם הפרויקט]
בעל/ת הפרויקט: [שם]
מוביל/ת טכנולוגי/ת: [שם]
נותן/ת חסות ניהולי/ת: [שם]
יחידת בסיס: [שם]
יחידות להרחבה: [רשימה וסדר עדיפות]
גרסה ותאריך: [להשלמה]

1. מטרת הפרויקט
   - מה מוקם, לאיזה צורך (מקושר ל-1.1 באפיון העסקי)
   - תוצר סופי ושימוש בו: [להגדיר]
   - מדד הצלחה מרכזי: [להגדיר]

2. עקרונות ההטמעה (ראו SKILL.md סעיף 5)

3. מצב פתיחה והשלמת פערים
   שאלות לאימות: האם האפיון הושלם ואושר? מה נבנה בפועל? האם היה פיילוט
   ומה תוצאותיו? אילו מקורות מידע וחיבורים קיימים? אילו יחידות כבר
   אופיינו? אילו החלטות פתוחות?
   מסמכי בסיס: [קישורים לאפיונים, סיכומי פגישות ומשימות]
   פערים המחייבים החלטה: [להשלמה]

4. שלבי העבודה (לכל שלב: פעולות, תוצרים, אחראי, מועד יעד, תנאי מעבר)
   א'. אימות וגיבוש בסיס
   ב'. אפיון יחידה נוספת
   ג'. בנייה
   ד'. בדיקות ופיילוט
   ה'. עלייה לאוויר והטמעה
   ו'. הרחבה (סדר, קצב וגורם מאשר לכל יחידה)

5. תבנית אפיון לכל שדה (תבנית 2)

6. יישום ראשוני
   מה נבנה ראשון, ואילו החלטות להשלים לפני הבנייה

7. תפקידים ואחריות (תבנית 3)
8. מדדי הצלחה (תבנית 4)
9. ניהול סיכונים (תבנית 5)

10. אישור התוכנית
    היקף הגרסה הראשונה | יחידת הפיילוט ומצבה | היחידה הבאה |
    משאבים ולוחות זמנים | החלטות פתוחות |
    אישור מקצועי / טכנולוגי / בעל הפרויקט (שם ותאריך)
```

## תבנית 4: מדדי הצלחה

לכל מדד: **ערך בסיס | יעד | תדירות מדידה | אחראי**. דוגמאות מהמקרה:
- שיעור הפריטים הרלוונטיים שתועדו
- שיעור הרשומות שהושלמו ואושרו
- זמן ממוצע למילוי ולאישור
- דיוק חילוץ AI לפי שדה, לפני תיקון אנושי
- שיעור התשובות שחייבו תיקון
- שיעור שימוש בקרב משתמשי היעד
- מספר ליקויים חוסמים ואירועי הרשאה
- שביעות רצון משתמשים ומאשרים

הערה: מדדי שימוש ושביעות רצון הם נקודת החיבור ל-`effectiveness-testing` (מדידה לפי NASSS אחרי העלייה לאוויר).

## תבנית 5: ניהול סיכונים

| סיכון | התמודדות |
|---|---|
| אי-בהירות מקצועית | הגדרות שדות מאושרות לפני פיתוח |
| מקורות חסרים או סותרים | כללי הכרעה והשלמה ידנית |
| שגיאות AI | הצגת מקור ובקרה אנושית |
| חשיפת מידע | הרשאות ובדיקת מגבלות שימוש |
| מורכבות יתר בין יחידות | הפרדה בין רכיבים משותפים לייעודיים |
| אימוץ נמוך | תהליך מילוי קצר, הדרכה ומעקב שימוש |
| תלות באדם יחיד | תיעוד, ממלאי מקום וחלוקת אחריות |
| הרחבה מוקדמת מדי | מעבר בין שלבים רק אחרי אישור תנאי הסף |
