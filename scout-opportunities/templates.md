# סקאוט — תבניות

## 1. התראת הזדמנויות

**כותרת:** `[סקאוט] {N} הזדמנויות — {תאריך}`

```
בוקר טוב איציק,

{אם יש שאלה פתוחה מתשובה קודמת — כאן, בשורה אחת}

━━ משרות לעצמך ━━

#1 · {תפקיד} — {חברה}
ציון: {X}/10 · {מיקום} · שכר: {מפורסם / הערכה: טווח / לא ידוע}
למה: {נימוק במשפט אחד}
להדגיש: {מקרה בוחן} — {למה בכמה מילים}
פעולה: {הגשה / פנייה ל-X}
{קישור}

━━ לידים ל-I2E ━━

#2 · {חברה} — מגייסים {תפקיד}
ציון: {X}/10 · {גודל} · {תעשייה}
הסיגנל: {מה הגיוס מרמז}
שירות רלוונטי: {needs-diagnosis / implementation-plan / effectiveness-testing}
{קישור}

━━ נפסלו מאז ההתראה הקודמת ({M}) ━━
· {תפקיד} — {חברה}: {סיבה ב-3–5 מילים}
· ...

━━
להמשך: השב למייל הזה, שורה לכל פריט שחשוב לך. לדוגמה:
כן 1
לא 2 — דרג נמוך
פספסת Challenge Group
פריט בלי שורה נשאר "ממתין".
```

## 2. חבילת פנייה (טיוטת Gmail)

**כותרת:** `[סקאוט] חבילת פנייה — {חברה} — {תפקיד}`

```
מסלול: {א' / ב'}
קישור למשרה: {קישור}

── קו"ח מותאמים / פרופיל ארגון ──
{תוכן}

── מכתב פנייה / טיוטת פנייה ראשונה ──
{תוכן}

── מה הודגש ולמה ──
{2–3 שורות}

── לבדוק לפני שליחה ──
{כל מה שסומן "הערכה" או "לא ידוע"}
```

## 3. כיול חודשי

**כותרת:** `[סקאוט] כיול חודשי — {חודש}`

```
החלטות החודש: {כן} כן · {לא} לא · {פספסת} פספסת
שיעור הסכמה: {X}% (יעד: 80%)

תפוקה לפי התראת LinkedIn:
| # | התראה | נבדקו | מעל הסף | אושרו |

המלצות:
1. להחליף התראה {#} ב: {מילות מפתח} — כי {סיבה}
2. {שינוי סף או משקל, אם צריך, עם דוגמה מהלוג}
```
