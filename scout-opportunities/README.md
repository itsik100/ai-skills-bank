# סקאוט — הזדמנויות

אייג'נט שמאתר ומעריך משרות לאיציק (מסלול א') ולידים ל-I2E (מסלול ב') מתוך התראות LinkedIn. רץ כ-scheduled task יומי.

## קבצים
- `SKILL.md` — הוראות ההפעלה המלאות.
- `templates.md` — תבניות: התראת הזדמנויות, חבילת פנייה, כיול חודשי, שורת לוג.
- `job-alerts-config.md` — תיק התראות LinkedIn, מקור אמת למשפך.
- `opportunities-log.md` — לוג כל ההזדמנויות שנבדקו והחלטות איציק.
- `learnings.md` — לקחים וכללי כיול. גוברים על ברירות המחדל ב-SKILL.md.

## מקורות משותפים
- `core/career-profile.md` — פרופיל קריירה מלא, מקרי בוחן וקריטריוני חיפוש.

## שימוש מומלץ
יש לטעון את `SKILL.md`, `learnings.md` ו-`core/career-profile.md` בתחילת כל ריצה. בסיום כל ריצה יש לעדכן את `opportunities-log.md`, וכל שינוי בהתראות LinkedIn גם ב-`job-alerts-config.md`.
