# רדאר אירועים — תבנית מייל

מייל HTML, `dir="rtl"`, גופן Arial, רוחב עד 680px. בלי אימוג'ים מלבד סימון קטגוריה.

```
כותרת: [רדאר אירועים] {N} חדשים — {DD/MM}

[לא לשכוח]  (רק אם יש)
- {שם} — {תאריך} — עדיין לא סימנת "נרשמתי". [קישור הרשמה]

[שאלה ממני]  (רק אם תשובה קודמת לא הייתה ברורה)

כנסים בישראל
{N}. {שם האירוע}  ·  ציון {X}/10  ·  {נטוורקינג / ידע / שניהם}
     {יום} {DD/MM}, {שעה} · {מקום} · {מחיר}
     למה כדאי: {משפט אחד}
     טיפ: {משפט אחד}
     [להרשמה]({קישור ישיר})

וובינרים ואונליין
{N}. ... (אותו מבנה, שעה בשעון ישראל)

עדכונים לפריטים במעקב
- {שם}: {מה השתנה} [קישור]

גבוליים (שורה אחת)
- {שם} · {תאריך} · {למה גבולי}

---
איך לענות: השב למייל, שורה לכל פריט:
כן N  ·  נרשמתי N  ·  לא N {סיבה}  ·  עוד כמו N
נבדקו היום: {מספר מקורות} מקורות, {מספר} חיפושים, {מספר} פריטים נפסלו.
```
