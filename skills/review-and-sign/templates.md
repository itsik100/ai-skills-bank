# review-and-sign — תבניות

## 1. באנר טיוטה (שורה ראשונה בתוצר)

```
טיוטה — לא חתומה
```

## 2. באנר חתום (מחליף את באנר הטיוטה, רק אחרי "כן" מפורש)

```
נחתם ע"י איציק אילוז, DD/MM/YYYY
```

אם התוצר אושר בסבב הראשון בלי אף שינוי, הוסף מתחת לבאנר החתום:

```
אושר ללא שינויים — ודא שנקרא
```

## 3. מקרא תגיות

התגית נכתבת מיד אחרי הפריט שהיא חלה עליו, באותה שורה.

| תגית | מתי |
|---|---|
| `[מונח]` | הנחה של האייג'נט, לא כתובה במקור |
| `[מחושב]` | מספר שחושב ממספרים במקור. החישוב מופיע בסעיף "ראיות" |
| `[מוצע]` | המלצה של האייג'נט, לא של המקור |
| `[לא מאומת]` | המקור טוען, אבל בלי ראיה |
| `[סתירה]` | שני מקורות (או שני מקומות באותו מקור) נותנים ערכים שונים. מציגים את שניהם |
| `[לא במקור]` | בעל תפקיד, תאריך או מספר שחסר במקור. לא ממציאים ערך |

פריט שנמצא במקור כלשונו לא מקבל תגית.

## 4. מספור פריטים לסקירה

כל פריט שאיציק עשוי לרצות לשמור, לחתוך, לתקן או להקדים מקבל מספר בסוגריים מרובעים בתחילת השורה:

```
[1] מוביל חדשנות והטמעת טכנולוגיות, מרץ 2023 – היום
[2] השימוש בכלי AI לניסוח פטנטים עלה לכ-57% מהתיקים
```

## 5. סעיף ראיות (תמיד בסוף התוצר)

```
── ראיות ──
מקורות:
· {קובץ} · עודכן {DD/MM/YYYY}
הנחות ופערים:
· {פריט} — {מה הונח, או מה חסר במקור}
חישובים:
· {מספר} = {החישוב, עם המספרים מהמקור}
מה נחתך:
· [{N}] {הטקסט המלא שנחתך} · סבב {V}
בדיקה:
· check.py: {הורץ — N ממצאים / לא הורץ: אין shell}
```

## 6. פורמט משוב (תשובה למייל, שורה לכל פריט)

```
שמור N
חתוך N
תקן N: {הערה}
הקדם N
```

פריט בלי שורה נשאר כמו שהוא.

## 7. שאלת חתימה

שיחה סינכרונית — שואלים פעם אחת, אחרי אישור:

```
קראת הכל ואתה עומד מאחוריו?
```

מייל אסינכרוני — השאלה בסוף הטיוטה, מתחת לסעיף "ראיות":

```
── חתימה ──
קראת הכל ואתה עומד מאחוריו?
אם כן, השב בשרשור הזה: חתום
```

## 8. שורת יומן חתימות

```
| {DD/MM/YYYY} | {אייג'נט} | {תוצר} | {מספר סבבים} | {מספר שינויים: שמור/חתוך/תקן/הקדם} | {כן/לא} |
```

## 9. עותק נקי לשליחה

אחרי החתימה, האייג'נט הקורא מפיק עותק נקי לשליחה. הגרסה החתומה, עם התגיות והראיות, היא הרשומה ונשמרת כמו שהיא.

| בגרסה החתומה (רשומה) | בעותק הנקי |
|---|---|
| באנר `נחתם ע"י ...` | אין |
| תגיות `[מונח]` `[מחושב]` `[מוצע]` `[לא מאומת]` `[סתירה]` `[לא במקור]` | אין |
| מספור `[N]` | אין |
| סעיף "ראיות" ובלוק החתימה | אין |
| התוכן עצמו | זהה, מילה במילה |

בדיקה לפני מסירה: `python3 skills/review-and-sign/check.py --clean clean.md`. נכשלת → לא מוסרים, מדווחים.
