# outreach-writer — תבניות

המבנים כאן הם שלד, לא נוסח להעתקה. כל הודעה נבנית סביב הפרט הספציפי של הנמען.

## 1. פנייה יזומה — פורמט מסירה

```
נמען: {שם} · {תפקיד} · {חברה}
סוג: {מגייסת / מקבל החלטות}
שפה: {עברית / אנגלית}
העוגן: {הפרט הספציפי שההודעה נבנית סביבו}

── הודעת חיבור ({N} תווים) ──
{טקסט}

── הודעת המשך (אחרי אישור החיבור) ──
{טקסט}

── תזכורת (אחרי 7 ימים בלי תשובה) ──
{טקסט}

── מה היה מחזק את ההודעה ──
{רק אם חסר מידע}
```

## 2. שלד — מגייסת

**חיבור:** {פרט עליה: מגייסת ל-X / פוסט על Y} → {איציק: מוביל הטמעת טכנולוגיה בארגונים} → {להיות בקשר}

**המשך:** תודה → {למה דווקא היא} → {הוכחה אחת: מקרה בוחן במספר} → "אשמח להיות על הרדאר שלך לתפקידי {X}" → סגירה

## 3. שלד — מקבל החלטות (ליד I2E)

**חיבור:** {הסיגנל: ראיתי שאתם מגייסים X / מטמיעים Y} → {איציק: עוזר לארגונים שהטכנולוגיה החדשה שלהם תיכנס לשימוש בפועל}

**המשך:** תודה → {הסיגנל ומה הוא בדרך כלל אומר} → {הוכחה אחת: מה קרה במקרה דומה} → "שווה 20 דקות לשמוע איך זה נראה אצלכם?" → סגירה

## 4. תגובה לפנייה נכנסת

```
מקור: {הודעה / פוסט}
מה נשאל: {שורה}

── תשובה ──
{טקסט: מענה → פרט התאמה אחד → צעד הבא אחד}
```

## 5. מכתב פנייה למשרה (עבור סקאוט)

```
משרה: {תפקיד} · {חברה}
מקרה בוחן מודגש: {שם} — {למה}

── מכתב ({N} מילים) ──
{כאב הארגון → מה איציק עשה במצב דומה → מה הוא יביא → בקשה לשיחה}
```

## 6. שורת לוג

```
| {תאריך} | {שם} | {תפקיד} | {חברה} | {מגייסת/מקבל החלטות/תגובה/מכתב} | {שפה} | {טיוטה/נשלח/תזכורת נשלחה} | {ענו/לא ענו/ממתין} | {הערה} |
```
